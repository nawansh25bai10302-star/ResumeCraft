# ResumeCraft — Project Statement

## Problem Statement

Creating and maintaining a professional resume manually can be time-consuming. Users may need to repeatedly update personal information, education, projects, skills, and other sections while also maintaining consistent formatting.

ResumeCraft addresses this problem by providing a structured Java application that collects resume information, validates user input, manages resume data, allows users to select a resume template, and generates formatted resume files.

## Scope of the Project

The project focuses on developing a menu-driven Java application for creating and managing resumes.

The scope includes:

- Collecting personal information
- Managing education details
- Managing experience details
- Managing project information
- Managing skills
- Validating user input
- Creating and viewing resumes
- Editing resume information
- Deleting resume information
- Selecting resume templates
- Formatting resume content
- Generating TXT output
- Generating HTML output
- Handling local file operations and file-writing errors

The current scope is limited to a local Java application. Database storage, user authentication, cloud storage, and a graphical user interface are not part of the current implementation.

## Target Users

ResumeCraft is intended for:

- Students
- Fresh graduates
- Internship applicants
- Job seekers
- Users who want to create a structured professional resume

## High-Level Features

1. Resume creation

## Expected Outcome

The expected outcome is a working Java application that allows a user to enter and manage resume information and generate a formatted resume using a selected template.

The project also demonstrates practical application of Java programming concepts including object-oriented design, collections, validation, exception handling, file I/O, and modular software organization.
